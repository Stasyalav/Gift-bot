# Gift-bot — подбор подарков во ВКонтакте

Чат-бот сообщества ВКонтакте: вы рассказываете, кому и на какой повод
нужен подарок, называете бюджет — бот возвращает 5 идей от GigaChat с
примерными ценами и объяснением, почему они подойдут.

## Что умеет

- ведёт диалог по-русски, без Markdown — ВК не понимает разметку;
- принимает описание и бюджет по частям: «Маме, любит книги» → «5000»;
- всегда требует бюджет и проверяет его **в коде**: каждая идея должна
  укладываться в сумму, ответам модели в этом вопросе не доверяем;
- просит ровно 5 разных идей, проверяет схему, категории и цены;
- при нарушении правил делает одну повторную попытку с пояснением ошибки;
- присылает приветственную картинку при старте и не повторяет её подряд;
- показывает кнопки «Другая подборка», «Изменить критерии», «Начать заново»;
- аккуратно сообщает об ошибках GigaChat и ВК, делит длинный текст на части;
- работает через Long Poll, без вебхуков, FastAPI, базы данных и Docker.

## Стек

- Python 3.12
- `vkbottle` — Long Poll и API ВКонтакте
- `gigachat` — GigaChat SDK
- `pydantic` — схема ответа AI
- `Pillow` — приветственные картинки
- `python-dotenv` — настройки из `.env`

## Быстрый старт

```powershell
# 1. Виртуальное окружение и зависимости
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

# 2. Настройки
Copy-Item .env.example .env
# откройте .env и заполните VK_TOKEN, VK_GROUP_ID, GIGACHAT_CREDENTIALS

# 3. Сертификат Минцифры для GigaChat
Invoke-WebRequest `
  -Uri "https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt" `
  -OutFile "certs\russian_trusted_root_ca.cer"

# 4. Проверки
.\.venv\Scripts\python.exe scripts\check_vk.py
.\.venv\Scripts\python.exe scripts\check_gigachat.py

# 5. Запуск
.\.venv\Scripts\python.exe run.py
```

Бот должен быть запущен постоянно. Напишите сообществу первым — ВК не
разрешает сообществу писать пользователю, который ещё не начинал диалог
(ошибка 901). Ссылка на диалог:

```
https://vk.me/club<ID сообщества>
```

## Настройки

Все секреты хранятся только в `.env`. Файл `.env` и папка `.venv`
исключены из Git.

| Переменная | Обязательна | Назначение |
|---|---|---|
| `VK_TOKEN` | да | ключ сообщества с правами «Сообщения» и «Фотографии» |
| `VK_GROUP_ID` | да | числовой ID сообщества |
| `GIGACHAT_CREDENTIALS` | да | ключ авторизации GigaChat |
| `GIGACHAT_SCOPE` | нет | `GIGACHAT_API_PERS` для физлица |
| `GIGACHAT_MODEL` | нет | по умолчанию `GigaChat-2` |
| `GIGACHAT_CA_BUNDLE_FILE` | нет | путь к PEM-сертификату Минцифры |
| `GIGACHAT_TIMEOUT_SECONDS` | нет | таймаут запроса, по умолчанию 60 |
| `GIGACHAT_MAX_RETRIES` | нет | повторы при сетевых ошибках, по умолчанию 2 |
| `LOG_LEVEL` | нет | `INFO`, `DEBUG` и т. п. |
| `MAX_BUDGET_RUB` | нет | верхний предел бюджета, если нужно ограничить |

Токен ВК: **Управление → Работа с API → Ключи доступа**. В настройках
сообщества должны быть включены сообщения и Long Poll («Входящие
сообщения»).

Ключ GigaChat: личный кабинет [developers.sber.ru](https://developers.sber.ru).
Для физического лица используется scope `GIGACHAT_API_PERS`.


## Приветственные картинки

Лежат в `assets/greetings/`. Поддерживаются JPG и PNG, желательно около
1200×800 и до 300 КБ. Бот выбирает случайный файл и не повторяет
предыдущий. После замены картинок перезапустите бота — список файлов и
кэш вложений читаются при старте.

Важно: ВК не принимает WebP при загрузке фото в сообщения, а PNG с
прозрачностью может показаться с чёрным фоном. Подробности — в
`assets/greetings/README.md`.

## Ограничения MVP

- Состояние диалога хранится **в памяти**. После перезапуска бота все
  диалоги начинаются заново — это осознанное решение, базы данных нет.
- Цены ориентировочные. Бот не гарантирует наличие в магазинах, не даёт
  ссылки на товары и не придумывает бренды.
- GigaChat может ошибаться. Ответ проверяется по схеме и бюджету, при
  ошибке делается одна повторная попытка, затем пользователь видит
  понятное сообщение.
- Один процесс, без горизонтального масштабирования и очередей.
- Бот не может написать пользователю первым — ВК вернёт ошибку 901.

## Если что-то не работает

- **`CERTIFICATE_VERIFY_FAILED`** — нет или не тот сертификат Минцифры.
  Нужен именно PEM-файл, первая строка `-----BEGIN CERTIFICATE-----`.
- **GigaChat 401/403** — проверьте `GIGACHAT_CREDENTIALS`, scope и модель.
- **ВК 901** — пользователь ещё не писал боту; попросите написать первым.
- **Бот не видит сообщения** — проверьте права токена («Сообщения»,
  «Фотографии»), включённые сообщения сообщества и Long Poll.
- **`photo is undefined`** — картинка в WebP или PNG с прозрачностью;
  пересохраните в JPG.
- **Логи** — `logs/bot.log`.

## Безопасность

`.env` и `.venv` не попадают в Git. Сертификат Минцифры публичный, его
можно хранить в репозитории. Не публикуйте токен ВК и ключ GigaChat.
