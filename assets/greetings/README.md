# Приветственные картинки

Сюда кладутся картинки, которые бот отправляет при старте подбора.

Требования:
- формат: **JPG** или **PNG**;
- размер: около **1200×800** (допускаются другие пропорции);
- вес: до **300 КБ**;
- без текста или с 1–2 словами.

## Важно про WebP

ВКонтакте не принимает WebP при загрузке фотографий в сообщения —
`photos.saveMessagesPhoto` возвращает ошибку `photo is undefined`.
Если картинка в WebP, пересохраните её в JPG:

```powershell
.\.venv\Scripts\python.exe -c "from PIL import Image; Image.open('assets/greetings/photo.webp').convert('RGB').save('assets/greetings/photo.jpg', 'JPEG', quality=92, optimize=True)"
```

## Прозрачность

PNG с прозрачным фоном ВК может показать с чёрным или белым фоном.
Надёжнее заранее положить картинку на кремовый фон `#F7EFE6` и сохранить
в JPG.

## Замена

Просто положите свои файлы в эту папку. Бот при запуске найдёт все
поддерживаемые файлы и будет выбирать их случайно, не повторяя одну и
ту же картинку подряд. Старые файлы можно удалить.

После замены картинок перезапустите бота — список файлов и кэш
загруженных вложений читаются при старте.
