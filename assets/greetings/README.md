# Приветственные картинки

Сюда кладутся картинки, которые бот отправляет при старте подбора.

Требования:
- формат: `.jpg`, `.png` или `.webp`;
- размер: около **1200×800**;
- вес: до **300 КБ**;
- единая палитра: кремовый, пудрово-розовый, золотистый, тёмно-коричневый;
- без текста или с 1–2 словами.

Файлы `01.jpg` … `06.jpg` — сгенерированные заглушки. Их можно заменить
своими фотографиями с теми же именами (или любыми другими — бот найдёт
все поддерживаемые файлы в этой папке).

Перегенерировать заглушки:

```powershell
.\.venv\Scripts\python.exe scripts\make_placeholders.py
```
